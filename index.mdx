Inscribe is the official compiler toolchain for the **Mentalogue Language** — a statically-typed, expression-oriented language designed for clarity and safety. From a single `.mtl` source file, Inscribe runs your code through lexing, parsing, type-checking, HIR/MIR lowering, and native code generation, targeting both Linux and Windows x86_64.

## What Inscribe Does

Inscribe takes `.mtl` source files and produces native executables, sandboxed artifacts, or intermediate compiler outputs. Every invocation runs through a full pipeline:

<Steps>
  <Step title="Type-check your source">
    `inscribe check` runs the complete pipeline through type inference and ownership analysis, reporting errors without producing any output file.
  </Step>
  <Step title="Build a native executable">
    `inscribe build` compiles your program to a native ELF64 or PE64 binary for the host or a specified target.
  </Step>
  <Step title="Run immediately">
    `inscribe run` compiles and executes in one step — or falls back to the sandboxed MIR interpreter when native codegen isn't supported for a construct.
  </Step>
  <Step title="Inspect intermediate outputs">
    `inscribe emit` dumps HIR, MIR, assembly, DWARF debug info, MLIB library files, and ABI headers for tooling and debugging.
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="Native Code Generation" icon="microchip" href="/cli/build">
    Produces standalone ELF64 (Linux) and PE64 (Windows) x86_64 binaries — no runtime dependency.
  </Card>
  <Card title="Sandboxed Execution" icon="shield-halved" href="/cli/sandbox">
    Run programs safely under the MIR interpreter with capability-gated access to stdin, stdout, and the network.
  </Card>
  <Card title="Incremental Compilation" icon="bolt" href="/tooling/incremental-compilation">
    Disk-backed cache across all pipeline stages — only recompile what changed.
  </Card>
  <Card title="Standard Library" icon="box-archive" href="/stdlib/overview">
    Built-in modules for math, strings, I/O, results, and HTTP — importable from any `.mtl` file.
  </Card>
  <Card title="MLIB Libraries" icon="cubes" href="/cli/emit">
    Package compiled symbols in the binary `.mlib` format with embedded source for distribution.
  </Card>
  <Card title="VS Code Extension" icon="code" href="/tooling/vscode-extension">
    Syntax highlighting, IntelliSense, and background diagnostics for `.mtl` and `.mlib` files.
  </Card>
</CardGroup>
