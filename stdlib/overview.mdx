The Inscribe standard library ships as source that is compiled alongside your own code. Every module is imported with a single `import` statement — no package manager, no manifest entries, no version pins. The compiler resolves paths relative to the stdlib root and lowers them together with your program.

## Two-Layer Architecture

The stdlib is deliberately split into two layers that serve different purposes.

**Pure Mentalogue layer** (`stdlib/core/` and `stdlib/io/`): everything that can be expressed in pure `.mtl` source lives here. These modules contain data transforms, arithmetic helpers, string inspection utilities, and console wrappers. They carry no operating-system dependencies of their own and can be reasoned about without knowing anything about the host platform.

**Runtime boundary layer** (`stdlib/runtime/`): these files contain _only_ extern function declarations — no bodies, no logic. They are the seam between Mentalogue code and the services the compiler or host runtime must provide: file I/O, process control, wall-clock time, networking, and platform ABI hooks. You should rarely need to import `runtime.*` directly; prefer the `core.*` and `io.*` wrappers instead.

<Note>
  `runtime.*` modules expose raw compiler-provided declarations that touch the host system directly. Calling them bypasses any wrapper-level safety logic. Use the higher-level `core.*` and `io.*` wrappers unless you are writing new stdlib modules yourself.
</Note>

## Importing Modules

Any module can be imported by its dotted path:

```
import core.math
import core.string
import io.console
import http.client
```

The import statement makes every top-level function in that module available in the current file's scope. There is no selective import syntax — all public symbols are brought in.

## Runtime Reference

The following declarations are the complete public surface of the two remaining runtime modules. They are documented here rather than on a dedicated page because each module contains only a single function.

**`runtime.process`**

```
fn exit(code: int)
```

Terminates the running process immediately with the supplied exit code. No destructors or deferred actions are run. Use sparingly; most programs should return a code from `main` instead.

**`runtime.time`**

```
fn unix_seconds() -> int
```

Returns the current wall-clock time as a Unix timestamp (whole seconds since 1970-01-01 00:00:00 UTC). Note that any function calling `unix_seconds` will be flagged as **non-deterministic** by the MIR determinism checker.

<Tip>
  If you only need elapsed time between two points in a single run, call `unix_seconds()` twice and subtract — no external dependency needed.
</Tip>
